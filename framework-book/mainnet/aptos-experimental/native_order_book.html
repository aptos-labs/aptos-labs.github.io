Module 0x7::native_order_book

Native order storage, keyed by (exchange, market, order_id) for single orders and (exchange, market, account) for bulk orders. Write API is set_ / delete_, gated by a TradingNativeCapability (re-checked via assert_valid on every call). Native state is read only on the validator side (Rust), never from Move.
